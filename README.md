# Агентное моделирование информационного взаимодействия человека и искусственного интеллекта в процессе принятия решений

Здесь будут храниться артефакты по моей научно-исследовательской работе.

**Автор:** Зацепина Дарья Викторовна
**Научный руководитель:** Ковальчук Сергей Валерьевич, канд. техн. наук, доцент

## Мотивация

- ИИ-ассистенты все чаще учавствуют в процессе принятия решений в разных областях.
- Существует множество таксономий взаимодействия человека и ИИ, однако нет универсальной структуры.
- Нет единого подхода метрик оценки взаимодействия.
- Теории поведения редко встроены в формальные модели взаимодействия с ИИ.

## Цель

Построить агентную модель, позволяющую анализировать и оптимизировать процессы принятия решений в различных сценариях.

## Задачи

1. Провести обзор и сравнительный анализ таксономий взаимодействия человека и искусственного интеллекта;
2. Выделить ключевые параметры взаимодействия и построить универсальную структуру;
3. Определить систему метрик оценки взаимодействия;
4. Построить агентную модель;
5. Провести сценарные эксперименты и сформулировать рекомендации по оптимизации.
